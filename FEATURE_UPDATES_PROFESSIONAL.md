# AccessLearn Professional Feature Update

This build includes the requested professional-level updates:

## AI Chatbot
- General question answering with Gemini when available.
- Clean fallback when API quota is exceeded.
- Notes-based chatbot mode.
- Suggested questions based on selected teacher notes.

## Smart Summarizer
- Summarizes pasted text.
- Summarizes teacher-uploaded notes.
- Supports file summarization for TXT, PDF, DOCX and PPTX when dependencies are available.
- Supports readable webpage/link summarization.
- Output format includes Key Points, Important Concepts, Quick Revision Notes and Final Summary.

## Teacher Resource Sharing
- Teachers can upload text notes.
- Teachers can upload PDF/DOCX/PPTX/TXT/Image/Video files.
- Teachers can add Google Drive/resource links and video links.

## Quiz System
- Students can generate topic-based quizzes.
- Teachers can generate and publish quizzes for students.
- Students can attempt published quizzes.
- Teacher quiz reports show student, quiz title, score and attempt date.

## Student Analytics
- Study time tracking on note detail pages.
- Teacher study report shows how long each student studied each note.

## Meeting Module
- Teachers can create meetings with date, time and meeting link.
- Students can view and join meetings.
